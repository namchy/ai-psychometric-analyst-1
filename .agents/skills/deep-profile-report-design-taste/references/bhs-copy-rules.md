# BHS Copy Rules

## Zabranjene riječi i fraze
- saradljiv
- ponašajni
- procjenski
- procjenskog
- AI interpretacija u glavnom report tijelu
- Način generisanja kao glavni metadata box
- zaposliti / ne zaposliti kao odluku reporta
- idealni kandidat
- fit score
- konačna odluka

## Preferirane zamjene
- loše: saradljiv
- bolje: spreman na saradnju / saradnička orijentacija

- loše: ponašajni
- bolje: obrasci ponašanja / radni stil

- loše: procjenski okvir
- bolje: okvir procjene / izvještaj / HR pregled
