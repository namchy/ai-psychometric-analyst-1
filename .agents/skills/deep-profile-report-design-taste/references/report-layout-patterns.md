# Report Layout Patterns

## Structured summary
- Glavni signal
- Tačka opreza
- Kako koristiti nalaz

## Integrated signal card
- Naslov
- 2-column grid:
  - Šta ovo znači u radu
  - Šta HR treba provjeriti
- Evidence block:
  - Dokazi iz procjena
  - Ličnost
  - Kognitivni rezultat
  - Motivacija

## Bad pattern
- jedan dugačak paragraf preko cijele kartice
- jedan red sitnih chipova
- dekorativni pillovi bez nove informacije
